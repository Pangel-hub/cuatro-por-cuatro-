# Registro de cambios — Rediseño responsive

## Versión 2.0 (rama feature/responsive-redesign)

- Se reforzó la identidad visual con paleta, jerarquía tipográfica, tarjetas y espaciado consistentes.
- Se añadieron puntos de adaptación para teléfono pequeño, teléfono, tableta, escritorio y escritorio amplio.
- Se mejoraron inputs y botones para interacción táctil y foco de teclado.
- Se añadieron estilos de movimiento reducido.
- Las tablas y el Gantt conservan desplazamiento horizontal contenido cuando el ancho no permite mostrarlos completos.
- Se añadió resaltado automático de la sección visible en la navegación.
- No se modificaron las fórmulas ni la función de simulación de producción.
- No se cambió la estructura de datos ni las reglas de despacho.
- La prueba física de dispositivos reales debe registrarse por el equipo; las dimensiones de CSS son objetivos de diseño, no pruebas físicas.
